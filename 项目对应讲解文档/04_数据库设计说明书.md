# 在线表格智能问卷系统数据库设计说明书

> 文档编号：OF-DBD-006  
> 版本：V1.0  
> 数据库：MySQL 8.0  
> 字符集：utf8mb4  
> 存储引擎：InnoDB

## 1. 编写目的

本文档说明在线表格智能问卷系统的数据库结构、数据表关系、字段定义、索引策略和安全约束，为系统开发、测试、部署及后续维护提供依据。

## 2. 设计目标

数据库需要支持用户管理、问卷编辑、在线填写、答卷分析、异常检测、体验反馈、AI 数据分析和多格式导出等业务。

设计遵循以下原则：

- 使用外键保证关联数据完整性。
- 使用唯一索引防止邮箱、公开码等关键数据重复。
- 问题和选项使用排序字段保证显示顺序稳定。
- 问卷删除后，其题目、答卷等关联数据级联删除。
- 密码只保存哈希值，不保存明文。
- 采用 `utf8mb4` 支持中文及特殊字符。

## 3. 数据库关系

```text
users
 ├─ questionnaires
 │   ├─ questions
 │   │   └─ question_options
 │   ├─ responses
 │   │   ├─ answers
 │   │   │   └─ answer_options
 │   │   └─ user_feedback
 │   ├─ response_sessions
 │   └─ export_tasks
 ├─ notification_settings
 └─ export_tasks
```

## 5. 索引设计

- `users.email`：唯一索引，加快登录查询并防止邮箱重复。
- `questionnaires.public_code`：唯一索引，用于公开问卷访问。
- `questionnaires(user_id, status)`：加快用户按状态查询问卷。
- `questions(questionnaire_id, sort_order)`：按顺序加载题目。
- `question_options(question_id, sort_order)`：按顺序加载选项。
- `responses(questionnaire_id, submitted_at)`：支持答卷列表和趋势统计。
- `responses.source`：支持来源分布统计。
- `response_sessions.session_token`：唯一定位填写会话。
- `export_tasks(user_id, created_at)`：支持导出记录查询。

## 6. 数据完整性设计

- 用户删除时，其问卷、通知设置和导出任务级联删除。
- 问卷删除时，其问题、选项、答卷、填写会话和反馈级联删除。
- 答卷删除时，其答案和选项关联级联删除。
- 会话关联答卷删除时，会话中的 `response_id` 设置为空。
- 外键和唯一索引共同防止无效关联和重复记录。

## 7. 安全设计

- 数据库密码通过 `backend/.env` 配置，不写入源代码。
- 用户密码使用 bcrypt 哈希保存。
- 管理接口通过 JWT 识别用户。
- 查询问卷、答卷和导出任务时同时校验当前用户编号。
- IP、邮箱等数据仅用于业务校验和分析，不在公开问卷接口中返回。
- 比赛提交包不包含真实 `.env`、业务数据库和用户隐私数据。

## 8. 数据库初始化

数据库初始化脚本位于：

```text
database/schema.sql
```

运行后会创建 `online_form` 数据库及全部空表，不包含测试账号、问卷和答卷数据。

后端连接配置示例：

```dotenv
ASYNC_DATABASE_URL=mysql+aiomysql://root:数据库密码@127.0.0.1:3306/online_form?charset=utf8mb4
```

## 9. 备份与恢复建议

- 比赛演示前导出一次完整 SQL 备份。
- 正式环境建议每日自动备份，并保留至少 7 个历史版本。
- 用户上传的头像和问卷背景应与数据库同时备份。
- 恢复时先导入数据库，再恢复上传文件，最后检查 `.env` 连接配置。

## 10. 设计结论

本数据库采用关系型结构保存用户、问卷、问题、答卷和导出任务，使用 JSON 字段保存可变的风险原因。整体结构满足问卷全生命周期管理、来源分析、异常答卷治理、AI 数据分析和多格式导出的需要，并通过外键、索引和用户权限校验保证数据一致性与安全性。
