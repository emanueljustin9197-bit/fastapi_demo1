# 在线表格智能问卷系统用户操作手册

> 文档编号：OF-UM-005  
> 版本：V1.0（评审稿）  
> 日期：2026-09-18

## 1. 使用说明

本手册面向问卷创建者和填写者，说明从登录、创建、发布到分析导出的完整操作。比赛本机演示默认访问：

- 前端：`http://localhost:5173`
- 后端接口文档：`http://localhost:8000/docs`

实际交付地址以部署环境为准。

## 2. 环境要求

- 推荐使用最新版 Chrome 或 Edge。
- 使用 AI 功能时，服务器必须能够访问 DeepSeek API。
- 二维码跨设备填写时，前端地址不能使用只对本机有效的 `localhost`，应配置局域网 IP 或正式域名。

## 3. 注册与登录

### 3.1 注册

1. 打开系统登录页。
2. 点击“立即注册”。
3. 输入显示名称、登录邮箱和至少 6 位密码。
4. 点击“注册并登录”。
5. 注册成功后自动进入工作台。

### 3.2 登录

1. 输入已注册邮箱和密码。
2. 点击“登录工作台”。
3. 若提示邮箱或密码错误，请核对输入后重试。

### 3.3 退出

点击顶部右侧退出图标。系统会清除当前浏览器中的登录状态并返回登录页。

## 4. 创建问卷

### 4.1 从模板创建

1. 点击顶部“创建表格”。
2. 在左侧选择模板分类，或在搜索框输入关键词。
3. 点击需要的模板卡片。
4. 系统进入编辑器并自动填入标题、说明、问题、选项和预计时间。
5. 根据实际需求继续修改。

系统内置员工满意度、客户满意度、活动报名、产品反馈、会议签到、培训反馈、候选人登记、市场需求等模板。

### 4.2 创建空白问卷

1. 在模板页点击“新建空白问卷”。
2. 输入表格名称和说明。
3. 使用“添加题目”区选择题型。

## 5. 编辑题目

### 5.1 支持的题型

| 题型 | 适用场景 |
|---|---|
| 单选题 | 只能选择一个答案 |
| 多选题 | 可选择多个答案 |
| 问答题 | 收集文字意见和描述 |
| 日期题 | 收集日期 |
| 评分题 | 收集 1 至 5 分评分 |
| 数字题 | 收集数量、年龄、金额等数字 |
| 电话题 | 收集电话号码 |

### 5.2 编辑方法

1. 在题目标题输入框中修改内容。
2. 使用题型下拉框切换题型。
3. 单选/多选题可修改、添加或删除选项。
4. 勾选“必填”后，填写者必须回答该题。
5. 点击“删除”移除题目。

保存前请确认每道题都有标题，选择题至少有一个有效选项。

### 5.3 AI 生成

1. 在右侧“AI 表格助手”中输入需求，例如“生成一份包含 8 道题的课程满意度调查”。
2. 点击“生成题目”。
3. 等待生成完成。
4. 逐题检查并人工修改，再保存或发布。

AI 输出仅作为初稿，涉及专业、医疗、法律等内容时必须人工审核。

## 6. 配置问卷

### 6.1 设置抽屉

点击顶部“表格设置”，右侧打开设置面板：

- 开启收集：已有问卷可立即发布或停止。
- 允许匿名填写：关闭后填写者必须输入姓名和邮箱。
- 每人限填一次：匿名按 IP、实名按邮箱判断。
- 最长填写时间：1 至 1440 分钟。
- 显示答卷结果：提交成功后展示本次填写内容。

点击“保存设置”写入问卷；点击“取消”、遮罩或按 Esc 放弃未保存设置。

### 6.2 设置背景

1. 在右侧“问卷背景”点击“选择背景”。
2. 选择 JPG、PNG 或 WEBP 图片，文件不超过 5MB。
3. 可在背景预览中查看效果。
4. 使用“更换背景”替换，或使用“移除”恢复默认背景。

### 6.3 预览

1. 点击顶部“预览”。
2. 点击“电脑”或“手机”检查不同宽度。
3. 预览会显示当前未保存修改，但不会提交答卷。
4. 点击右上角关闭或按 Esc 返回编辑器。

## 7. 保存与发布

### 7.1 保存草稿

点击“保存草稿”。保存前系统会检查标题、题目和选项。草稿只能在管理端查看，不能公开填写。

### 7.2 发布问卷

1. 点击“发布表格”。
2. 发布成功后系统生成公开链接和二维码。
3. 点击“复制链接”分享，或下载二维码图片。
4. 二维码填写会记录为“二维码”来源；微信中打开会记录为“微信转发”。

### 7.3 停止和重新开启

在“我的表格”找到正在收集的问卷，点击“停止”；也可在编辑器设置中关闭“开启收集”。停止后公开链接不可填写。重新开启后原公开链接继续有效。

## 8. 管理问卷

1. 点击顶部“我的表格”。
2. 查看问卷总数、累计回收、正在收集和平均完成率。
3. 输入名称关键词搜索，或按状态筛选。
4. 每份问卷可执行：编辑、分析、发布/停止、复制、删除。

删除会同时影响关联答卷，执行前必须确认。比赛演示时不建议删除演示主问卷。

## 9. 填写问卷

### 9.1 匿名问卷

打开链接后直接填写。标有“必填”的问题必须完成。点击“提交答卷”后等待成功提示。

### 9.2 实名问卷

除题目外，还需填写姓名和格式正确的邮箱。

### 9.3 超时和重复提交

- 若超过设置时间，提交时会提示填写时间已结束。
- 开启“每人限填一次”后，重复提交会被拒绝。

### 9.4 提交后反馈

提交成功后可对填写体验评分，选择问题类型并填写补充说明。该反馈不修改已提交答卷。

## 10. 查看分析

### 10.1 选择问卷

点击顶部“表格分析”，从页面中的问卷选择器选择目标问卷。

### 10.2 总览与趋势

- 总览查看总答卷、有效答卷、平均填写时长和完成率。
- 选择最近 7 天或 30 天查看提交趋势。
- 来源表查看公开链接、二维码和微信转发的数量及占比。

### 10.3 逐题统计和答卷详情

展开逐题统计查看选择分布或文字回答。点击答卷记录可查看每道题的具体回答。

### 10.4 异常答卷

1. 点击异常检测区的“重新扫描”。
2. 查看风险分和原因。
3. 对确认异常的答卷标记为无效。
4. 对误报答卷恢复为有效。

风险规则是辅助筛选，不能只看分数直接删除数据。

### 10.5 AI 洞察

1. 先选择 7 天或 30 天范围。
2. 点击生成 AI 洞察。
3. 查看关键发现、建议和对应证据。
4. 在追问框提出具体问题。
5. 点击新建/清空对话开始新的上下文。

若 AI 服务不可用，趋势、来源、逐题统计和答卷详情仍可正常使用。

### 10.6 填写体验反馈

在分析页查看填写者提交的平均评分、问题数量和文本说明，用于改进问卷内容与填写流程。

## 11. 导出数据

1. 点击顶部“导出数据”。
2. 选择需要导出的问卷。
3. 选择 Excel、CSV 或 JSON。
4. 选择全部答卷、近 7 天或自定义日期。
5. 决定是否包含答卷元数据。
6. 点击创建导出任务。
7. 在下方任务列表点击“下载”。

格式建议：

- Excel：人工查看和二次分析。
- CSV：导入统计软件或数据库。
- JSON：系统接口和程序处理。

当前版本后端重启后旧导出任务文件可能需要重新生成。

## 12. 账号设置

1. 点击顶部“设置”或右侧用户信息。
2. 可更换头像、显示名称、手机号码和所属组织。
3. 登录邮箱不可直接修改。
4. 点击“保存资料”后顶部账号信息同步更新。

## 13. 常见问题

### 13.1 发布后手机打不开

若链接是 `localhost`，它只指向手机本身。请让前后端监听局域网地址，并将 `FRONTEND_BASE_URL` 配置为电脑局域网 IP 或正式域名。

### 13.2 AI 提示未配置

服务器需要在 `.env` 中配置 `DEEPSEEK_API_KEY`。不要把密钥写进前端或比赛材料。

### 13.3 问卷显示已停止

问卷不是 `active` 状态。回到“我的表格”发布，或在设置中开启收集。

### 13.4 二维码来源没有数据

必须从系统生成的二维码打开；直接复制普通公开链接会记录为公开链接。

### 13.5 Excel 下载失败

先刷新导出记录。若后端刚重启，请重新创建导出任务。

## 14. 演示数据建议

比赛前准备一份“校园活动满意度调查”，至少包含 20 份答卷，覆盖三种来源、正常/异常答卷、实名/匿名示例和填写体验反馈。这样能一次展示趋势、来源、异常检测、AI 洞察和导出能力。
