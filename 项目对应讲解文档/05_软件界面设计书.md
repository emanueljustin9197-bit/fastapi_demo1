# 在线表格智能问卷系统软件界面设计书

> 文档编号：OF-UID-004  
> 版本：V1.0（评审稿）  
> 日期：2026-09-18

## 1. 设计定位

产品面向需要高频创建、管理和分析问卷的用户，界面采用克制、清晰、工作台式的视觉语言。设计不追求营销页式装饰，重点保证信息扫描、重复操作和数据比较效率。

关键词：专业、可靠、安静、高效、可解释。

## 2. 信息架构

```text
登录 / 注册
└─ 工作台
   ├─ 创建表格
   │  ├─ 模板库
   │  ├─ 问卷编辑器
   │  ├─ 表格设置抽屉
   │  └─ 问卷预览
   ├─ 我的表格
   ├─ 表格分析
   │  ├─ 数据概览
   │  ├─ 提交趋势与来源
   │  ├─ 逐题统计与答卷详情
   │  ├─ 异常答卷
   │  ├─ AI 洞察与追问
   │  └─ 填写体验反馈
   ├─ 导出数据
   └─ 账号设置

公开填写链接
└─ 填写 → 提交结果 → 本次答卷（可选）→ 体验反馈
```

## 3. 视觉规范

### 3.1 色彩

| 用途 | 参考色 | 说明 |
|---|---|---|
| 顶部导航 | `#222938` | 稳定、低干扰的深色工作区 |
| 主操作 | `#3F73D8` | 发布、保存、提交等主要动作 |
| 页面背景 | `#F1F3F6` | 与白色内容区形成轻层次 |
| 内容卡片 | `#FFFFFF` | 主要阅读和操作表面 |
| 主文字 | `#263453` | 标题和关键数据 |
| 次文字 | `#7C8799` | 说明、时间、辅助信息 |
| 边框 | `#DDE3EA` | 低对比度分区 |
| 成功 | 绿色系 | 收集中、提交成功、正常状态 |
| 危险 | 红色系 | 删除、错误、无效答卷 |

### 3.2 圆角与阴影

- 普通按钮和输入框：6px 圆角。
- 卡片和工具面板：不超过 8px 圆角。
- 阴影仅用于卡片、悬浮抽屉和模态层，避免装饰性漂浮。

### 3.3 图标

- 顶部导航采用 Lucide 线性图标。
- 导航图标统一 18px，线宽 1.8。
- 品牌图标 24px。
- 图标与文字间距 8px，未选中为低饱和浅色，选中为白色。
- 仅图标按钮必须提供 `title` 和 `aria-label`。

### 3.4 字体层级

| 层级 | 建议尺寸 | 用途 |
|---|---:|---|
| 页面标题 | 24px | 页面首要标题 |
| 面板标题 | 16-18px | 卡片、抽屉和模块标题 |
| 正文 | 13-15px | 表格、说明和操作文本 |
| 辅助文本 | 9-12px | 标签、时间、状态说明 |
| 关键数字 | 22-28px | 统计指标 |

不使用随视口线性缩放的字体，保证不同屏幕下信息层级稳定。

## 4. 全局布局

### 4.1 顶部导航

桌面端高度 72px，包含：

1. 左侧品牌标识和“在线表格”。
2. 中间主导航：创建表格、我的表格、表格分析、导出数据、设置。
3. 右侧账号头像、名称、邮箱和退出按钮。

当前页面使用蓝色背景强调；导航过多时允许横向滚动，不挤压文字。

### 4.2 内容区域

- 桌面端左右边距 42px，底部保留 64px。
- 页面标题区包含标题、简短说明和右侧操作按钮。
- 页面主体优先使用全宽布局，数据页面避免右侧大片空白。
- 编辑器采用“主编辑区 + 305px 辅助区”，小屏自动单列。

### 4.3 响应式断点

| 宽度 | 调整 |
|---|---|
| `≤ 900px` | 账号文字隐藏、页面边距缩小、编辑器变单列 |
| `≤ 700px` | 导航仅显示图标，内容区边距 16px |
| `≤ 620px` | 模板单列、概览 2×2、预览工具栏压缩、设置抽屉全宽 |

## 5. 页面设计

### 5.1 登录与注册

桌面端采用品牌视觉区和账号表单区的双栏结构。品牌区说明产品价值，表单区只保留当前任务所需字段。移动端隐藏大面积视觉区，直接呈现账号表单。

状态：默认、输入聚焦、提交中、认证失败、登录失效提示、登录/注册模式切换。

### 5.2 我的表格

顶部显示 4 个统计指标，下面为搜索、状态筛选和表格列表。列表提供编辑、分析、发布/停止、复制、删除操作。状态使用“草稿、收集中、已关闭”徽标区分。

设计重点：

- 常用操作位于同一行，减少进入详情后的往返。
- 空数据、加载和错误状态占据表格区域，不改变页面骨架。
- 删除使用危险色并二次确认。

### 5.3 模板库

左侧为固定分类，右侧为搜索和模板卡片。模板预览直接体现题目结构，而不是使用无关插画。卡片显示标题、说明、题目数量和预计时间。

交互：分类切换、关键词搜索、清除搜索、使用模板、新建空白、返回当前编辑。

### 5.4 问卷编辑器

页面由四部分组成：

1. 顶部操作：更换模板、表格设置、预览、保存、发布。
2. 概览条：题目数、必填数、最长填写时间、创建方式。
3. 主编辑区：基本信息、题目卡片、选项和快速添加题目。
4. 辅助区：发布链接、背景设置、AI 表格助手。

题目卡片使用连续编号强化顺序。选择题的选项图形与题型一致。快速添加区采用固定网格，避免按钮随内容跳动。

### 5.5 表格设置抽屉

点击顶部“表格设置”后，右侧打开 400px 抽屉，页面背景加半透明遮罩。

抽屉结构：

- 头部：标题、说明、关闭按钮。
- 状态块：当前草稿/收集/停止状态。
- 基础：开启收集、允许匿名填写。
- 填写规则：每人限填一次、最长填写时间。
- 提交后：显示答卷结果。
- 底部固定：取消、保存设置。

支持关闭按钮、取消、点击遮罩和 Esc。保存期间禁止关闭，避免请求状态不明确。

### 5.6 问卷预览

预览使用全屏层，顶部提供电脑/手机分段控制和关闭按钮。预览显示当前未保存内容，但提交按钮禁用并明确提示不会保存答卷。

### 5.7 表格分析

分析页使用纵向信息带：

1. 问卷选择与时间范围。
2. 总览指标。
3. 提交趋势折线图与来源统计表。
4. AI 洞察和证据。
5. 逐题统计。
6. 答卷列表及详情。
7. 异常答卷和人工复核。
8. 填写体验反馈。

趋势图保持稳定纵横尺寸。来源使用表格展示链接、二维码、微信转发的数量和占比，便于精确比较。

### 5.8 导出中心

左侧为导出任务配置，右侧/下方为最近任务记录。格式使用三选一按钮组，范围使用选项按钮，元数据使用复选框。成功任务提供下载，失败任务显示错误原因。

### 5.9 账号设置

顶部展示头像、名称和邮箱。主区域编辑名称、电话和组织，侧栏展示账号概览和资料完善度。邮箱作为登录标识不可编辑。

### 5.10 公开填写页

以单列阅读为主，最大宽度限制在舒适范围。自定义背景时，问卷内容保持高对比白色表面。选择题按钮整行可点，必填题显示红色标识。

提交成功页依次显示：成功状态、本次答卷（按设置）、体验评分、问题类型和补充说明。

## 6. 组件与交互规范

### 6.1 按钮

- 主按钮：每个局部区域通常只保留一个。
- 普通按钮：次要动作。
- 危险按钮：删除、标记无效等不可忽略动作。
- 禁用状态降低透明度并禁止重复提交。

### 6.2 表单

- 标签始终可见，不只依赖 placeholder。
- 数值输入标出单位、最小值和最大值。
- 开关只用于即时二元状态。
- 单选、多选和格式选择采用符合语义的控件。

### 6.3 状态反馈

| 状态 | 呈现方式 |
|---|---|
| 加载 | 原区域显示“正在加载/处理中”，按钮禁用 |
| 空数据 | 说明当前没有数据，并保留下一步操作 |
| 成功 | 绿色提示或状态页 |
| 错误 | 红色提示，使用后端可理解消息 |
| 已复制 | 按钮短暂变为“链接已复制” |

## 7. 可访问性要求

- 弹层使用 `role="dialog"` 和 `aria-modal="true"`。
- 仅图标按钮包含可读标签。
- 键盘可通过 Tab 到达主要控件，Esc 可关闭预览和设置抽屉。
- 文本和背景保持足够对比度。
- 移动端触控按钮保持稳定尺寸，不因文字加载改变布局。
